# Pinterest Pin Image Prompts

Paste-ready prompts for ChatGPT image generation. 10 per guide, 7 guides.

## How to use

1. Paste one prompt as-is. Every prompt already specifies 2:3 vertical (1000×1500), the brand palette, and the exact overlay text.
2. **Always proofread rendered text.** Image models still misspell. If a word comes out wrong, reply "regenerate, the word X is misspelled" rather than starting over.
3. If a pin comes back too busy, reply: "same image, 30% less clutter, more negative space around the text block."
4. Vary the pins you publish per guide — Pinterest suppresses near-duplicates. Ten different compositions per guide is roughly 10 weeks of fresh pins at one per week.

### Brand style block (already baked into every prompt below)

> Palette: deep navy #102a43, warm cream #fbf6ed, muted teal #2f6f73, coral accent #e46f55, brass gold #c99c54. Editorial workshop-magazine feel — warm, real, slightly lived-in. No logos, no visible brand names on packaging, no watermarks, no stock-photo gloss.
